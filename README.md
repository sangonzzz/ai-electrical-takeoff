# AI Electrical Takeoff

Analyze residential **vector** electrical plan PDFs and produce a reviewable takeoff:
per-room counts, marks on the plan, CRUD corrections, optional bill of materials
(boxes, cable length, priced lines).

Demo input: City of Escondido PAADU public-domain plans — four sheets in
`data/plans/escondido_plans.pdf`.

## Architecture (summary)

Hybrid pipeline: PyMuPDF geometry finds **where** symbols and rooms are; the sheet
legend plus Claude (optional) decide **what**. FastAPI + ARQ + Postgres + Redis serve
async jobs; React overlays detections in PDF coordinates (`viewBox` = viewport).

See `docs/architecture.md` (Mermaid) and `docs/SPEC.md` (source of truth). Agent
ownership: `AGENTS.md`.

## Install

Requirements: Python 3.12, [uv](https://docs.astral.sh/uv/), Node 22 + pnpm (frontend),
Docker Desktop (full stack).

```bash
cp .env.example .env
# optional: set ANTHROPIC_API_KEY for LLM legend / adjudication
uv sync --all-packages --group dev
cd web && corepack enable && pnpm install && cd ..
```

## Run with Docker

```bash
docker compose up -d
# API http://localhost:8000/docs  ·  Web http://localhost:5173
make demo   # uploads demo PDF via backend/scripts/demo_upload.py
```

Default `ENGINE=fake` returns the Plan 1 fixture so the UI works before the real
pipeline is selected. Set `ENGINE=real` once `analyze_sheet` is the production path.

## CLI

```bash
uv run takeoff analyze data/plans/escondido_plans.pdf --page 0 --out out/plan1.json --debug
uv run takeoff eval --pdf data/plans/escondido_plans.pdf --out eval/reports
uv run takeoff eval --results-dir out --out eval/reports
uv run takeoff schema
```

## Evaluation

Hand-count templates: `eval/ground_truth/plan{1..4}.counts.yaml` (see `eval/COMO_CONTAR.md`).
`takeoff eval` writes `eval/reports/latest.{md,json}` plus overlay PNGs. CI runs
`python -m eval.regression` against `eval/baseline.json` when a report exists.

**Eval results:** ground-truth counts are still templates (zeros) until Santiago fills
them. Pipeline overlays for all four sheets live under `out/` when generated by Agente 2.

## AI usage and models

| Env | Default | Use |
|-----|---------|-----|
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | Legend interpret, adjudicate, vision baseline |
| `ANTHROPIC_MODEL_CHEAP` | `claude-haiku-5-5` | Reserved (not vision baseline) |
| `ENABLE_LLM` | true | Off → rules-only, warnings, no raise |

Disk cache: `.cache/llm/`. Sonnet 5.5 uses `tool_choice: auto` + strict tools (forced
tool choice returns HTTP 400). Approx cold legend cost ~$0.05/sheet; see Agente 4 status.

## Counting rules and assumptions

Full list: `coordination/DECISIONS.md` and SPEC §2. Highlights:

- Count keys: `category` and `category.subtype`; skip `status=deleted`.
- Fan with center `J` = one ceiling fan (not fan + junction box).
- Open-plan rooms split by nearest label; Exterior / Attic special rooms.
- BOM: plan length + vertical allowance; 10% waste at `compute_bom`; `nm_14_3` only
  between 3-way switch ends.

## Known limits

- Detection precision still improving (false positives on switches/receptacles).
- Real end-to-end accuracy needs filled ground-truth YAMLs.
- Some BOM prices are `verified: false` (Agente 8 status).
- GitHub Actions workflow push needs `gh` token scope `workflow`.
- Scanned/raster plans are out of scope.
